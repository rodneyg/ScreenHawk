Release notes

Changelog

New features, improvements, and fixes in each release. Dates reflect merged updates. Chrome Web Store availability may follow after review.

November 27, 2026

Short-window prompts and shortcut feedback

Improved

  • Keep Cancel visible in short prompt windows by allowing the dialog to scroll.
  • Show a badge on the toolbar icon when a keyboard shortcut cannot start, then clear it after recovery.
November 27, 2026

Incognito history and keyboard focus fixes

Fixed

  • Keep keyboard focus on Ask after a request error so keyboard users can continue through the controls.
  • Do not save captures from incognito windows to local history. The answer still appears in the tab, and regular window history works as before.
November 26, 2026

Screenshot history and form drafting

New

  • Choose a text field from the toolbar popup or press Command+Shift+Z on Mac or Ctrl+Shift+Z elsewhere. Select a highlighted text area or plain text input, then use Help me write to review a draft before inserting it.

Improved

  • History keeps up to 50 screenshot answers on your device. Open details to see the saved crop, question, and answer, revisit the source page when available, or delete the entry.

Fixed

  • Screenshots that are still being processed for history no longer reappear after you clear it.
  • The homepage OpenAI API pricing link now opens the API rate tables.
November 23, 2026

Keyboard-only area selection

New

  • Select an area using the keyboard. Move with the arrow keys, press Enter or Space to mark each corner, and hold Shift for finer movement.
November 21, 2026

Drafting, capture history, and installation

New

  • Draft text from a selected text area with the Help me write button. Review the draft before inserting it. ScreenHawk checks that the field is still editable, its text has not changed, and the draft fits its length limit.
  • Open History in the toolbar popup to review or delete up to 20 saved capture answers. Questions, answers, timestamps, and thumbnails are stored on your device.
  • Install from the Chrome Web Store using the link on the homepage, or build a ZIP for manual installation.

Improved

  • The homepage shows the current default model and clearer steps for loading an unpacked build. Install commands wrap on narrow screens.
  • The popup and Ask dialog use softer, translucent buttons. The popup's Settings button has a larger touch target.
  • The website privacy policy explains aggregate page views and Chrome Web Store link click counts. The extension does not run analytics.

Fixed

  • Valid history entries stay accessible when another saved entry is malformed.
  • Settings treat invalid saved key or model values as missing, so you can enter a key and use the default model.
November 20, 2026

ScreenHawk 1.0.1

Fixed

  • Restored answers for selected areas by switching the default model to GPT-6 Luna. Saved GPT-4.1 nano selections automatically use the new default. Other custom models stay selected.
November 20, 2026

ScreenHawk 1.0.0

New

  • Select part of a Chrome tab, ask a question, and read an OpenAI answer on the same page.
  • Save your own OpenAI API key and model in the extension options. ScreenHawk 1.0.0 used GPT-4.1 nano by default.
  • A product site with a homepage, privacy policy, support page, changelog, and terms.

Improved

  • Chrome grants temporary access to the active tab for each capture. Only the selected crop and your question are sent to OpenAI when you submit.
