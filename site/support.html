Support

Email Rodney Gainous Jr at rodney.gainous@gmail.com or open a GitHub issue. Include your Chrome version, ScreenHawk version, and the steps that led to the problem. Leave out API keys and private screenshots.

ScreenHawk says my key is missing

Open chrome://extensions, choose ScreenHawk’s details, and open its extension options. Paste your OpenAI API key and save it before trying again.

OpenAI rejects my key

Confirm the key is active and belongs to an OpenAI API project with access and billing set up. If OpenAI revoked the key, replace it in ScreenHawk’s options and save. If the error mentions a usage limit, check your OpenAI project’s limits and billing.

The capture shortcut does nothing

Open chrome://extensions/shortcuts and assign ScreenHawk an unused shortcut. Return to a regular web page and try it again. You can also start a capture from the ScreenHawk toolbar button.
