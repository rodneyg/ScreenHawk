Add to Chrome Install from source on GitHub

How it works

  1. Open ScreenHawk

    Click ScreenHawk in the Chrome toolbar or use its capture shortcut.

  2. Select an area

    Drag a box around a chart, a message, or any visible part of the page.

  3. Ask a question

    Submit your question and read the answer on the same tab.

Bring your own OpenAI key

Save your OpenAI API key in ScreenHawk’s options. The key stays in local extension storage. The default model is gpt-6-luna. When you submit a question, ScreenHawk sends the selected image and your question directly to OpenAI using your key.

What does it cost?

You pay OpenAI directly, based on your API usage. The model, image size, and answer length affect the price. See OpenAI API pricing.

Install from source

You can also try the development build from source.

Use Chrome 106 or later and Node.js 24 with npm.

View the ScreenHawk repository

git clone https://github.com/rodneyg/ScreenHawk.git
cd ScreenHawk
npm ci
npm run build
  1. Open chrome://extensions and turn on Developer mode.
  2. Click Load unpacked and select the dist folder.
  3. Open ScreenHawk’s options and save your OpenAI API key.

Frequently asked questions

Do I need a ScreenHawk account?

ScreenHawk has no account. You’ll need an OpenAI API key from a project with API access and billing set up. API billing is separate from a ChatGPT subscription.

What part of my screen gets sent?

When you submit a question, ScreenHawk sends the rectangle you selected and the question you typed directly to OpenAI. Read the privacy policy for details.

Where can I use ScreenHawk?

Use it on regular web pages in desktop Chrome. Chrome restricts extensions on internal pages such as Settings and on the Chrome Web Store.

How do I change the capture shortcut?

Open chrome://extensions/shortcuts and choose a shortcut for ScreenHawk’s capture command.
