Privacy policy

Rodney Gainous Jr publishes ScreenHawk. The ScreenHawk Chrome extension has no account, developer server, or telemetry.

Marketing website analytics

This website uses Vercel Web Analytics for anonymous, aggregate page views and Chrome Web Store link clicks. Analytics uses no cookies. Tracked page URLs omit query strings and fragments. Clicks include only a fixed referral category. Website analytics never receives extension questions, screenshots, or API keys.

On your device

ScreenHawk stores your own OpenAI API key and model choice on this device in chrome.storage.local. The default model is gpt-6-luna. When you start a capture, Chrome captures the visible tab. ScreenHawk crops the image to the area you select on your device.

ScreenHawk saves up to 50 capture questions and answers in local history on this device. New entries include a timestamp, a compressed selection image and thumbnail, and the source page address and title when available.

What OpenAI receives

When you choose Ask, ScreenHawk sends only the selected crop and your typed question as content directly to api.openai.com. When you choose Generate draft, the only page or user text it sends is the reviewed field label and the instructions you type. It checks the selected field's value on your device before inserting the draft so it can preserve any changes made while you were drafting. You submit the form yourself. The request includes your chosen model and uses your own API key for authorization. The answer or draft appears on the page where you started the request. Local history is for capture questions and answers. OpenAI’s privacy policy applies to processing by OpenAI.

Rodney Gainous Jr does not receive, sell, or share your key, screenshots, or questions.

Chrome permissions

  • activeTab gives ScreenHawk temporary access to the tab where you start a capture or draft.
  • scripting loads the capture or draft interface on demand.
  • storage saves your OpenAI API key, model choice, and capture history on this device.
  • https://api.openai.com/* lets ScreenHawk send your submitted questions and draft instructions directly to OpenAI.

Remove your data

Delete saved entries in the ScreenHawk popup's History, remove your key in Settings, or uninstall the extension to remove its local storage. You can also revoke the key from your OpenAI account. Contact OpenAI about any data it has already processed.
