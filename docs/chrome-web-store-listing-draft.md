## Name

ScreenHawk

## Short description

Select part of a web page, ask a question about it, and read the answer on the same page.

## Long description

ScreenHawk lets you ask about part of a page in Chrome. Select a chart, an image, or a passage, then type a question about it. The answer appears on the same page.

Start from the ScreenHawk toolbar button or press Command+Shift+S on Mac or Ctrl+Shift+S on other platforms. Drag over the area you want to ask about, enter your question, and click Ask. Press Escape to cancel or close the overlay.

Add your own OpenAI API key in ScreenHawk Settings. Use the default model or choose an OpenAI model that accepts images. When you click Ask, ScreenHawk sends the selected image crop and your question directly to OpenAI using your key.

For a form draft, select an editable text area, choose Draft for field in the popup, then click Help me write. Review the field label, add instructions, and review the generated text before inserting it. You submit the form yourself.
